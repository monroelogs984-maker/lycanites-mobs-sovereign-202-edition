# Lycanites Mobs - Sovereign 202 Edition

A from-scratch port of [Lycanites Mobs](https://lycanitesmobs.com) (official source:
Forge 1.20.1, `gitlab.com/Lycanite/LycanitesMobs`) to NeoForge 1.21.1, built to serve as
the core creature mod for Sovereign 202.

Repo: https://github.com/monroelogs984-maker/lycanites-mobs-sovereign-202-edition

See [PORT_PLAN.md](PORT_PLAN.md) for scope, phase breakdown, and current status.
